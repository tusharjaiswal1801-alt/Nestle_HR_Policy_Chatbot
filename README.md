# Nestle HR Policy Chatbot

This repository contains the notebook for the Nestlé HR policy chatbot and the PDF used as the source document.

## Files included
- `Nestle_HR.ipynb`
- `the_nestle_hr_policy_pdf_2012.pdf`

## Local setup
1. Create a local `.env` file in the same folder and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook and run all cells.

## Important
- Do not commit your real `.env` file.
- Keep your API key private.
- The repository intentionally keeps only the notebook and PDF needed for the project.
